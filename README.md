# Music Rating

### Музыкальный веб-сервис с системой оценок и рецензий

Music Rating — веб-приложение для прослушивания, оценки и обсуждения музыкальных композиций.

Сервис объединяет музыкальный каталог, страницы исполнителей, пользовательские рейтинги и рецензии. Основная особенность проекта — система оценки треков по пяти отдельным критериям, на основе которых формируется общий рейтинг.

В приложении также реализованы регистрация и авторизация, личный кабинет и административные функции для управления каталогом.

## Система рейтингов

Вместо одной общей оценки пользователь выставляет баллы по пяти критериям:

1. Текст
2. Ритм
3. Стиль
4. Индивидуальность
5. Атмосфера

На основе этих значений рассчитывается оценка пользователя, а затем общий рейтинг композиции.

Оценки сохраняются в базе данных и используются для отображения рейтингов. Для каждой пары «пользователь — композиция» предусмотрена уникальная запись оценки.

Помимо числовой оценки можно написать рецензию с заголовком и текстом.

## Техническая реализация

### Серверная часть

Серверная логика написана на PHP.

Основные функции приложения включают:

- Обработку регистрации и авторизации
- Работу с пользовательскими сессиями
- Проверку прав доступа
- Добавление, изменение и удаление записей
- Обработку оценок и рецензий
- Загрузку и хранение путей к медиафайлам

Для взаимодействия с MySQL используется PDO. SQL-запросы, принимающие пользовательские значения, реализованы с использованием подготовленных выражений.

Пароли хранятся в виде хешей, созданных через `password_hash()`. При входе используется `password_verify()`.

Административные действия защищены проверкой роли пользователя.

### База данных

Приложение использует реляционную базу данных из шести основных таблиц.

| Таблица | Назначение |
|---|---|
| `users` | Аккаунты пользователей и роли |
| `artists` | Исполнители |
| `genres` | Музыкальные жанры |
| `songs` | Композиции, описания и пути к файлам |
| `ratings` | Пользовательские оценки |
| `reviews` | Текстовые рецензии |

Таблицы связаны через внешние ключи.

Например, запись об оценке связана с пользователем и композицией, а каждая композиция — с исполнителем и жанром.

На уровне базы предусмотрены ограничения уникальности, в том числе для предотвращения дублирования оценок одной композиции одним пользователем.

### Работа с файлами

Аудиозаписи и изображения хранятся отдельно от базы данных.

В таблицах сохраняются пути к файлам, а сами файлы находятся в каталогах:

- `uploads/audio/` — музыкальные композиции
- `uploads/covers/` — обложки и изображения исполнителей

Загрузка новых медиафайлов доступна администратору.

Для папки `uploads` добавлены правила Apache, ограничивающие просмотр содержимого каталога и доступ к файлам с исполняемыми PHP-расширениями.

## Локальный запуск

Проект можно запустить через XAMPP или аналогичное окружение с PHP, Apache и MySQL/MariaDB.

### 1. Подготовка проекта

Скачать репозиторий и поместить его в папку `htdocs`.

Пример расположения:

`C:\xampp\htdocs\MUSIC_site_portfolio`

### 2. Запуск сервера

Открыть XAMPP Control Panel и запустить:

- Apache
- MySQL

### 3. Импорт базы данных

Открыть phpMyAdmin:

`http://localhost/phpmyadmin/`

Создать базу данных:

`music_rating_db`

Импортировать демонстрационный SQL-файл `music_portfolio.sql` из репозитория.

### 4. Настройка подключения

В корневой папке проекта создать файл `config.local.php`:

```php
<?php

$host = 'localhost';
$dbname = 'music_rating_db';
$username = 'root';
$password = '';
```

Указанные значения подходят для типовой локальной установки XAMPP. Если настройки MySQL отличаются, их необходимо изменить.

Файл `config.local.php` не включён в Git, поскольку содержит локальные параметры подключения к базе данных.

### 5. Запуск приложения

Открыть в браузере:

`http://localhost/MUSIC_site_portfolio/`

Для проверки пользовательской части можно зарегистрировать новый аккаунт.

Административные функции доступны пользователю с ролью `admin`.

Для репозитория подготовлены тестовые данные, позволяющие проверить основные функции приложения.

В демонстрационную базу входят:
